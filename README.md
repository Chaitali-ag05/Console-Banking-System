# Console Banking System

A Java-based Console Banking System that allows users to perform basic banking operations through a command-line interface. The project follows a layered architecture using Service, Repository, Domain, and Exception handling components.

## Features

* Open a new bank account
* Deposit money
* Withdraw money
* Transfer funds between accounts
* View account transaction statements
* List all accounts
* Search accounts by customer name
* Input validation and custom exception handling

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Collections Framework
* UUID for unique identifiers
* Java Streams API
* IntelliJ IDEA
* Git & GitHub
